## GitHub Pages — beginner steps
1. Sign in to GitHub as `coep05`.
2. Open your profile and choose **Repositories**.
3. Click **New**.
4. Repository name: `coep05.github.io`
5. Set it to **Public**.
6. Create the repository.
7. Open the new repository and choose **Add file → Upload files**.
8. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
9. Click **Commit changes**.
10. Go to **Settings → Pages**.
11. Under **Build and deployment**, choose **Deploy from a branch**.
12. Select branch **main** and folder **/(root)**, then click **Save**.
13. Wait a few minutes. Your website should be published at:
   `https://coep05.github.io/`

If GitHub asks for a different Pages configuration, use the current option that publishes the `main` branch from the repository root.
